# Lab-Exercise-4

## Aim:
To Design a wireframe diagram for a generic application or website using Balsamiq



## Algorithm:
Start

Open the generic application in a web browser.
Display the Login Page.
Enter the Email ID.
Enter the Password.
Click the Login button.
Validate the entered login credentials.
If the credentials are invalid, display an error message and allow the user to enter them again.
If the credentials are valid, navigate to the Dashboard Page.
Display the Dashboard, including: 10.Navigation menu ~ Task summary ~ Task overview ~ Recent tasks ~ Notifications ~ Calendar ~ Project overview 11.Allow the user to select options such as Profile, Projects, Tasks, Calendar, Messages, Reports, Settings, and Logout. 12.If Logout is selected, end the user session and return to the Login Page. 13.Stop.
